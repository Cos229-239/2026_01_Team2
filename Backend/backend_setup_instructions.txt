Phase 1: Directory & Asset Initialization

#---Follow these steps in order to set up the backend environment:---/

1.	Create Assets FOLDER (Not a file)
	Navigate to your backend/ folder.
	Create a new directory/folder named assets .
	Path check: your-project/backend/assets/



2.	Fix Python "Alias" Error (If app.py doesn't run)
	-If you see the "App Execution Aliases" message, your terminal is confused.
	-Try running the command with py instead of python : your-project/backend > py app.py
	 	-If that fails, try: your-project/backend > python3 app.py



3.	Database Migration Setup (Dev Workflow)
 	-We have transitioned from db.create_all() to Flask-Migrate for professional schema management.
	 	#---One-Time Setup Commands:
			1.	pip install flask-migrate
			2.	flask db init (Creates the migration folder)
			3.	flask db migrate -m "initial migration" (Scans models)
			4.	flask db upgrade (Creates tables in database.db )

	 	*Note: From now on, use flask db upgrade to sync your database structure.

4.	Confirm Directory Accessibility
	 	-Verify the structure:
backend/ 
	|── app.py
	|── migrations/ (Generated after flask db init)
	|── database.db (Generated after flask db upgrade) 
	|── assets/

3.	Installation
	 	-Once (.venv) is active: 
			cd Backend 
				pip install 
					-r requirements.txt

4.	Running the Backend Server 
	-python app.py
	-Verification: http://127.0.0.1:5000 (Should see "Team 2 Flask Server is Running")

#---INTEGRATION WORKFLOW (Frontend & Backend)---/

	1.	User selects game layout on Frontend.
	2.	Frontend sends GET /api/game/init?game_type=standard .
	3.	Backend triggers initialize_game() .
	4.	Backend calls generate_grid(20, 20) .
	5.	Backend returns JSON object (grid metadata).
	6.	Frontend renders 20x20 CSS Grid.
