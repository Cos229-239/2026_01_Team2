# React (Next.js)
## How to run
1) Install Node.js
    - https://nodejs.org/en
2) Verify Install
    - check for version in the terminal`node -v`
    - check for the shortcut in the terminal`npm -v`    
3) Change directory to `/frontend/` in the terminal
4) `npm run dev`
5) [Check localhost:3000](http://localhost:3000/)
